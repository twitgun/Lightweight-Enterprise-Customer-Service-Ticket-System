# 修复问题

按以下流程修复指定问题：

1. **复现**：描述复现步骤、涉及角色与接口（如 manager 分配工单）；
2. **定位**：从前端调用链（`web/src/api/`）追踪到后端控制器与服务（`server/src/*/`），确认根因；
3. **最小修复**：只改必要代码，保持风格与既有约定一致；
4. **验证**：
   - 后端：`npm start` 后调用相关接口验证（登录、越权、边界输入）；
   - 前端：`npm run dev` 后走一遍页面流程；
   - 回归：确认相邻功能（实时推送、状态流转、统计）未被破坏；
5. **留痕**：若涉及行为变更，补充/更新 `08-测试用例.md` 或 `09-飞书-项目变更记录.md`。

# 代码审查

对当前改动执行代码审查：

1. 用 `git status` / `git diff` 确认本次改动范围；
2. 逐文件对照 `AGENTS.md` 的规范要点检查（代码风格 / 测试 / API 约定）；
3. 重点检查安全项：
   - 接口是否缺少 JWT / 角色守卫，是否存在越权读取他人数据；
   - SQL 是否参数化（TypeORM 参数绑定），避免拼接注入；
   - 前端是否对用户输入做转义，避免 XSS；
   - 是否泄露密钥、令牌或敏感日志；
4. 输出问题清单：`严重度（高/中/低） | 文件:行号 | 问题 | 修改建议`；
5. 无问题时给出结论「审查通过」。
